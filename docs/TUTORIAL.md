# Tutorial: Getting Started

This tutorial will guide you through creating your first evolutionary simulation.

1. **Define your Agent**: Inherit from `Agent` or `NeuroAgent`.
2. **Implement Sensors**: Override the `sense` method.
3. **Implement Actions**: Override the `act` method.
4. **Define Fitness**: Override `evaluateFitness`.
5. **Run Evolution**: Use `evolution_core` to manage the population.
