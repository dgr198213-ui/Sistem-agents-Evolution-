# Foraging Example

This example demonstrates neuroevolution applied to a foraging task. Agents must learn to find food in the environment and bring it back to their home base.

## Features
- NEAT-inspired neuroevolution.
- Dynamic environment with food respawning.
- Fitness based on successful food delivery.

## Running the example
```bash
nim c -r examples/foraging/example_foraging.nim
```
