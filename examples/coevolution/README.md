# Coevolution Example

This example demonstrates competitive coevolution between two populations: predators and prey.

## Features
- Simultaneous evolution of two competing species.
- Arms race dynamics: predators evolve hunting strategies, prey evolve evasion.
- Complex fitness landscape based on survival and successful hunts.

## Running the example
```bash
nim c -r examples/coevolution/example_coevolution.nim
```
